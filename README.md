# 当代戏精生存指南 · 超市促销级精神解药

一个把「当代人的精神内耗」做成超市促销海报的网页小玩意。黄底红字、吊牌价签、锯齿边、爆炸贴——用最吵闹的视觉，讲最清醒的道理。

## 在线访问

- 线上版本：https://drama-queen-guide.apps.workbuddy.host/?sharecode=NTDZ3BXA4N

## 本地打开

无需任何依赖、无需构建，直接双击 `index.html` 即可（也可以起个静态服务：`python -m http.server 8000`）。

## 目录结构

```
.
├── index.html   # 单文件应用：结构 + 样式 + 交互全在里面
└── .nojekyll    # 让 GitHub Pages 跳过 Jekyll 处理
```

## 说明

- 纯静态单文件，零依赖、零构建，任何静态托管都能跑
- 视觉体系：`#FF0000` 红 / `#FFD700` 黄 / `#0066FF` 蓝 / `#141414` 墨黑 / `#fffbe8` 米白
- 移动端自适应
